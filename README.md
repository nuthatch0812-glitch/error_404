# 아리타 자기와 조선 도공: 역사를 되살리다

> 일본 아리타 자기의 화려한 도자 문화 뒤에 가려진 조선 도공의 강제 이주와 정착의 역사를 알리는 인터랙티브 웹페이지

## 📖 프로젝트 소개

이 프로젝트는 임진왜란 이후 일본으로 강제 이주된 조선 도공들의 역사를 시각적이고 상호작용적인 방식으로 전달합니다. 아리타 자기의 아름다운 미학 뒤에 숨겨진 도공들의 삶, 기술 전승, 그리고 두 나라 도자 문화의 융합 이야기를 담아냅니다.

### 핵심 스토리라인

1. **화려한 표면** - 사용자는 먼저 아리타 자기의 화려한 외형에 매료됩니다
2. **금이 가는 순간** - 스크롤하며 자기 표면에 검은 금이 점점 생깁니다
3. **조각이 흩어짐** - 자기가 여섯 조각으로 갈라져 각기 다른 방향으로 밀려납니다
4. **숨겨진 역사** - 조각들 사이에서 조선에서 규슈를 거쳐 아리타까지의 도공 이동 경로가 나타납니다
5. **재결합** - 마지막에 조각들이 다시 모여 원래 모양으로 돌아오며, 각 균열마다 도공의 이름과 연도가 표시됩니다

## 🎬 주요 기능

### 섹션별 상세 설명

#### 1. 영웅 섹션 (Hero Section)
- **높이**: 100vh
- **특징**: 아이보리색 배경에 아리타 자기 한 점을 중앙에 크게 배치
- **정보**: 작품명과 제작 연도만 작게 표시
- **애니메이션**: 부드러운 페이드인 및 스케일 애니메이션

#### 2. 균열 섹션 (Crack Section)
- **스크롤 기반 애니메이션**: 사용자의 스크롤 진행도에 따라 실시간 변화
- **단계별 진행**:
  - 0-30%: 붉은 문양 사이에 검은 금이 생기고 점점 길어짐
  - 30-100%: 자기가 여섯 조각으로 갈라져 바깥쪽으로 흩어짐
- **기술**: Canvas를 이용한 부드러운 분할 애니메이션

#### 3. 지도 섹션 (Migration Map)
- **시각적 표현**: 조선, 규슈, 아리타의 위치를 표시
- **이동 경로**: 붉은 문양의 선을 그대로 이어 지도 위의 이동선으로 활용
- **도공 정보**: 스크롤 진행도에 따라 도공의 이름과 활동 연도가 나타남
- **상호작용**: 각 지역에 마우스 호버 시 추가 정보 표시

#### 4. 재결합 섹션 (Reassembly Section)
- **조각 모음**: 흩어진 여섯 조각이 점진적으로 중심으로 모여듦
- **텍스트 오버레이**: 각 조각의 균열마다 도공의 이름과 연도 표시
- **구성**: 처음의 온전한 자기와 대비되는 새로운 내러티브 창출
